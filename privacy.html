Privacy policy

Effective date: November 12, 2026

This policy applies to the Local CLI OAuth client described on this website. The client is operated solely by its owner and runs locally on the owner’s computer.

Data accessed

The application accesses only the Google account data required to perform commands explicitly requested by the user. Depending on the OAuth permissions granted, this may include Gmail message metadata and content. The application does not request access on behalf of website visitors.

How data is used

Data is used exclusively to execute and display the user’s requested Google Workspace CLI operations. It is not used for advertising, profiling, training machine-learning models, or unrelated purposes.

Storage

This website stores no application data and uses no analytics, cookies, or tracking scripts. OAuth credentials are stored locally by the CLI using its encrypted credential storage. Any command output retained on the owner’s computer remains under the owner’s control.

Sharing and third parties

The operator does not sell or share Google user data with third parties. API requests go directly between the locally running CLI and Google. This static website is hosted by GitHub Pages, whose standard server logging and privacy practices apply to website visits. No Google API data is sent to GitHub Pages.

Retention and revocation

The website retains no Google user data. Locally stored OAuth credentials remain until deleted by the user or revoked through the user’s Google Account security settings. Users may revoke access at any time through Google Account third-party access settings.

Contact

Privacy questions may be raised through the repository issue tracker.
