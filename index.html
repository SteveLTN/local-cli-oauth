Local CLI

A local automation client.

This site supports the OAuth consent configuration for a private instance of the open-source gws CLI. The application runs locally on its owner’s computer; this website does not provide an online service or collect account data.

What the application does

After explicit Google OAuth consent, the CLI can perform user-initiated Google Workspace API requests, including reading and managing the owner’s Gmail messages. Access is limited to the permissions shown on Google’s consent screen.

Availability

This is a locally operated tool, not a public application or a service offered to other users.
